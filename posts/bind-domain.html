把域名 glamy.cn 绑到 GitHub Pages 的步骤

2026-09-18

1. 仓库里放一个 CNAME 文件

仓库根目录的 CNAME 文件内容只有一行：glamy.cn。在 GitHub Pages 设置里填自定义域名时它也会自动生成，提交进仓库是为了防止下次 push 被清掉。

2. GitHub 侧配置

仓库 → Settings → Pages → Custom domain，填入 glamy.cn 并保存。等 DNS 校验通过后，勾选 Enforce HTTPS（证书由 GitHub 自动签发）。

3. 阿里云 DNS 解析记录

记录类型   主机记录   记录值
CNAME     www       glameyzhou.github.io
A         @         185.199.108.153
A         @         185.199.109.153
A         @         185.199.110.153
A         @         185.199.111.153

@ 的四条 A 记录是 GitHub Pages 的官方 IP，www 走 CNAME 指向 glameyzhou.github.io。

4. 验证

DNS 生效后（通常几分钟到半小时），浏览器访问 https://glamy.cn 即可打开博客。
